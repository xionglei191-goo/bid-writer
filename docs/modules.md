# 模块说明

## 后端

- `bid_writer_v2.database`：显式迁移和数据库连接。
- `bid_writer_v2.knowledge`：扫描、解析、OCR、拆解、重构、审核、发布和检索。
- `bid_writer_v2.production`：项目、要求、目录、章节生成、证据和导出。
- `bid_writer_v2.app`：统一 FastAPI 应用入口。

## 前端

- 工作台：任务、指标和风险。
- 知识工程：来源、处理队列、文档、知识单元、审核、发布、检索测试。
- 项目生产：招标解析、项目参数、响应矩阵、目录、章节编辑和版本。
- 模板资产：工艺、表格、流程图、组织架构图、横道图和企业模板。
- 质量交付：质量门禁、视觉复核、正式导出和验收。
- 系统设置：模型、OCR、目录和功能开关。
