# 技术标生产与知识工程架构

## 目录边界

- `01_原始标书库`：唯一原始资料来源，不由生产系统改写。
- `02_知识库`：标准文档、知识单元、重构草稿、审核记录、模板资产和已发布知识。
- `03_生产系统/bid_writer_app`：代码、迁移、测试和本地运行索引。
- `04_交付与报告`：正式交付文件、内部审查包和验收报告。

## 运行边界

生成模块只读取 `02_知识库/06_已发布知识库` 对应的 SQLite 发布索引。待审核、驳回、停用和旧 Markdown 内容不会进入检索结果。SQLite 可以删除并从知识资产重建，不能替代知识库文件本身。

## 主流程

```text
原始资料 -> 扫描去重 -> 标准化文档 -> 知识单元 -> 重构草稿
                                  -> 人工审核 -> 发布索引 -> 项目生成
招标文件 -> 项目解析 -> 响应矩阵 -> 章节编制合同 -> 证据审查 -> 正式导出
```

深度研究报告只进入 `docs/research`，技术决策进入 `docs/adr`，两者不在运行时调用。
